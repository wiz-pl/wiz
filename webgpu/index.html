Wiz → WGSL: an elementwise kernel

The kernel is Wiz source (webgpu/kernels/add.wiz); the WGSL in webgpu/build/ is generated from it by webgpu/tools/wgsl.mjs, which reads the syntax tree printed by wiz parse. The expected column is Wiz's own interpreter (#eval), not JavaScript arithmetic. Three kernels are shown here (add, maxMul, mix); the Deno harness runs the same modules over 130-element inputs too (three workgroups).
