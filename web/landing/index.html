Dependently typed · quantitative · self-hosted

A small language with big ideas.

Wiz is a dependently typed programming language with quantitative types, observational equality, and a self-hosted compiler that reaches native code through C and LLVM.

Read the guide Try the playground

Install a toolchain

curl -sSfL -o tower-init.sh https://raw.githubusercontent.com/wiz-pl/wiz/master/scripts/tower-init.sh
echo 'ad9c3a25a846f0316947e1529799dce9c6eccd4bd57fc8c7440a9e3ec371133c  tower-init.sh' | sha256sum -c -
sh tower-init.sh
export PATH="$HOME/.tower/bin:$PATH"
tower default nightly

Or with Nix: nix profile install github:wiz-pl/wiz#tower. More in the installation guide.

What it is

A learning project and the basis of a course in the style of Software Foundations: every stage of the implementation is a set of exercises, with a test suite that says when you got them right.

  • Quantitative types

    Quantities 0, 1 and ω on binders, with quantity polymorphism. Erased arguments cost nothing at run time, and a linear value is used exactly once.

  • Observational equality

    An impredicative, proof-irrelevant Prop, function extensionality, and a cast that computes on data.

  • Data as descriptions

    inductive and structure elaborate to indexed descriptions with μ/ν: dependent pattern matching, mutual and indexed families, sized types and codata.

  • Self-hosted, native

    The kernel, frontend and compiler check and compile themselves; erasure to an IR with reference counting, C and LLVM backends, and a C FFI with header import.

Get started

Wiz runs on x86_64 Linux (glibc 2.27 or later). Pick one of these, or read the full installation guide for editors and a first project.

  1. Install a toolchain with tower

    Tower works like elan or rustup: it puts wiz and grail shims on PATH and keeps toolchains per project.

    curl -sSfL -o tower-init.sh https://raw.githubusercontent.com/wiz-pl/wiz/master/scripts/tower-init.sh
echo 'ad9c3a25a846f0316947e1529799dce9c6eccd4bd57fc8c7440a9e3ec371133c  tower-init.sh' | sha256sum -c -
sh tower-init.sh
export PATH="$HOME/.tower/bin:$PATH"
tower default nightly

    Or with Nix: nix profile install github:wiz-pl/wiz#tower. More in the tower guide.

  2. Run it without a checkout

    The binaries are on the public Cachix cache, so Nix can fetch instead of building:

    cachix use badlydrawnwizards
nix run github:wiz-pl/wiz#wiz -- check hello.wiz   # `#grail` for grail

  3. Build from a checkout

    Everything the compiler and tests need comes from the development shell:

    nix develop         # the toolchain; writes this machine's paths to grail.local.wiz
lake build          # the library and the `wiz` executable
lake test           # the test suite (`lake test -- --list` for the groups)

    See building.md for CI, caches and the rest.
